# @agon/cli

The `agon` command.

```
agon validate [agon.yaml]            validate a config and summarize it
agon plan [agon.yaml] [-n N] [-s S]  show the sessions a run would execute, no browser or model needed
agon personas [list|show <id>]       browse the built-in persona library
agon schema                          JSON Schema for agon.yaml (editor support)
agon run / compare / trace / export  coming with the llm, adapters, exporters and stats packages
```

Global flags: `--json` for machine-readable output, `--no-color`.
